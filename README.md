# 📚 Gerenciador de Cadastro de Alunos (Python/Streamlit)

Projeto desenvolvido para gerenciar o cadastro e consulta de alunos usando Python, Streamlit e SQLite. Focado em demonstrar proficiência em desenvolvimento Full-Stack e boas práticas de banco de dados.

## 🌟 Funcionalidades

* **CRUD Básico:** Inserção e Consulta de alunos.
* **Busca Inteligente:** Consulta por CPF parcial (usando LIKE).
* **Interface:** Formulários intuitivos desenvolvidos com Streamlit.
* **Segurança SQL:** Uso de parâmetros (`?`) para prevenir SQL Injection.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python
* **Web Framework:** Streamlit
* **Banco de Dados:** SQLite3
* **Manipulação de Dados:** Pandas
